# Деплой на Vercel (Flutter Web)

В проекте уже есть всё нужное: папка `web/`, `vercel.json` и `build_web.sh`.
Vercel сам скачает Flutter и соберёт сайт (первая сборка занимает 5–10 минут).

## Вариант A. Через GitHub (рекомендуется)
1. Создайте репозиторий на GitHub и загрузите в него **содержимое этой папки**
   (так, чтобы `pubspec.yaml` и `vercel.json` лежали в корне репозитория).
2. На vercel.com нажмите **Add New → Project** и выберите репозиторий.
3. Ничего не меняйте в настройках сборки — они берутся из `vercel.json`
   (Framework Preset: Other). Нажмите **Deploy**.
4. Каждый следующий `git push` будет автоматически обновлять сайт.

## Вариант B. Через Vercel CLI
```
npm i -g vercel
vercel login
vercel --prod
```
Запускать из корня проекта (где лежит `vercel.json`).

## Вариант C. Собрать у себя и загрузить готовый сайт
Нужен установленный Flutter:
```
flutter pub get
flutter build web --release
cd build/web
vercel --prod
```
При вопросе про настройки выберите «Other», Output Directory — `.`.

## Проверка перед деплоем
```
flutter run -d chrome
```

## Заметки
- Музыка в браузере стартует после первого касания экрана (запрет автозвука).
- Сохранения хранятся в браузере (localStorage) — на другом устройстве
  или после очистки данных сайта прогресс не сохранится.
- Если сборка падает на версии Dart — в `build_web.sh` используется ветка
  `stable`; убедитесь, что `sdk:` в `pubspec.yaml` не новее текущего stable Flutter.
- Две игры — это два отдельных проекта на Vercel (у каждой свой архив).
